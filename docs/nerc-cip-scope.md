# NERC CIP scope boundary

This repository is an information-protection engineering example, not a NERC CIP control implementation, compliance assessment, audit opinion, or substitute for registered-entity obligations. It does not establish that a document contains BES Cyber System Information (BCSI), decide whether information is Critical Energy/Electric Infrastructure Information, determine impact categorization, or interpret regulatory exceptions.

The contextual BCSI detectors are synthetic heuristics for exploring versioned classification-as-code. Real operational configurations and access instructions can be sensitive even when no detector matches; a match is not proof of legal or regulatory status. False positives and false negatives are expected until qualified subject-matter experts test and approve detectors with authorized content.

Use only synthetic artifacts in the demo share. Never upload actual BES Cyber System data to a public issue, pull request, fixture corpus, or unapproved test tenant. Route any production classification, disclosure, retention, or incident question through the organization's compliance, legal, security, and registered-entity processes.
